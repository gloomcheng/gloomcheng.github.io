# Blog interaction contract

- Classification: `APPLICATION` of the existing gloomcheng identity; this work does not redesign the brand.
- Owner/version: gloomcheng personal site, Blog style guide v1 (2026-09-02).
- Fixed identity decisions: seed paper/ink/teal/orange/mint palette, LINE Seed TW display face, Noto Sans TC reading face, IBM Plex Mono technical face, hard editorial rules and the seed-beast master assets.
- Service-specific decisions: chronological archive hierarchy, article measure, metadata rhythm, legacy-link redirects, and a hero illustration layer that never shares a plane with text.

## User and information contract

| Field | Contract |
|---|---|
| User goal | Find an old essay or technical note, understand when and why it was written, and read it without knowing Drupal. |
| Entry condition | The reader enters from the site header, a search engine, an old `tayanswa.tw` link or another post. |
| Primary action | Choose an article from the latest list or chronological year archive. |
| Visible feedback | Native links expose hover and focus states; the destination shows a breadcrumb, title, type and publication date. |
| State model | Default, hover, keyboard focus and active page are visible. Empty sections show plain text. Legacy redirects show a readable link if automatic navigation is unavailable. There is no loading or disabled control because all pages are static. |
| Fallback | Missing legacy images keep meaningful alt text or a broken-media boundary; title-only Drupal records explicitly say that no separate body survived. Unknown routes use the static host's normal 404. |
| Completion and exit | Reaching an article is completion. Breadcrumbs and the article footer return to Blog or the profile. |
| Accessibility | Semantic headings and lists, skip link, visible focus, minimum 44px primary targets, readable measure, responsive tables/code, no required motion, and reduced-motion-safe transitions. |
| Information architecture | `/blog/` is one chronological archive; `/blog/<legacy-path>/` is the canonical post; the old root path redirects to that canonical post. Drupal content types and tags remain import provenance, not reader-facing navigation. |
| Component semantics | Site header = global navigation with stable `Blog / Resume` labels; latest list = recent entry points; year group = chronological navigation; post metadata = provenance; legacy notice = migration context, not an alert; seed-beast panel = decorative identity layer with no overlaid text; inline footnote code = jump link to the structured References ledger, never a modal. |
| Validation scenarios | Desktop and 320px archive; essay and code-heavy article; title-only record; old-path redirect; inline footnote → References → back-to-citation keyboard route; reduced motion. |
| Governance | Source lives in `gloomcheng/gloomcheng.github.io`; content imports are generated by `scripts/import-tayanswa.mjs`; changes use pull/commit history and browser QA before deployment. |
