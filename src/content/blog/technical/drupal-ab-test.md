<p>最近因在學校授課之故，又燃起想試做 A/B test 的念頭。想說 Drupal 這麼神奇，應該也會有 A/B test 的工具吧，果不其然。</p>

<p><a href="https://www.drupal.org/project/abtest" title="A/B test module">A/B test</a>：提供一套 API 函式，可以用來實作 A/B test。不過看來是得自己先在 Drupal 做出兩個頁面，再隨機分配給訪客瀏覽。</p>

<p><a href="https://www.drupal.org/project/optimizely" title="optimizely module">Optimizely</a>：用來介接 <a href="https://www.optimizely.com/">optimizely.com</a> 提供的服務，是從《Growth Hack 這樣做》這本書看到的服務。這服務好像可以直接從 optimizely.com 的後台直接改成 A/B 不同的版面配置，得花時間試試。</p>
